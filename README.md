# AI-Assisted Warehouse Bottleneck Detection

## Project Overview
An MBA academic project focused on identifying warehouse bottlenecks, analysing order delays, and improving operational efficiency using Python, Jupyter Notebook, and Power BI.

AI tools assisted in project development. The analysis uses Python-based data processing and predefined rule-based logic.

## Problem Statement
Warehouse delays during picking, packing, and dispatch can affect order fulfilment, delivery performance, and costs. This project analyses warehouse operations to identify delay patterns and potential improvement areas.

## Tools Used
- Python and Pandas – Data cleaning and analysis.
- Jupyter Notebook – Python execution.
- Power BI – Interactive dashboards and KPI visualisation.
- Excel/CSV – Dataset handling.
- GitHub – Project documentation and version control.
- Claude AI – Development assistance.

## Methodology
1. Generated a synthetic warehouse dataset.
2. Cleaned and processed data using Python.
3. Performed exploratory data analysis.
4. Identified bottlenecks using rule-based logic.
5. Created interactive Power BI dashboards.
6. Validated analysis results.

## Key Findings

| KPI | Result |
|---|---:|
| Total Orders | 2,000 |
| Completed Orders | 1,941 |
| Delayed Orders | 328 |
| On-Time Delivery | 83.1% |
| Packing-Stage Delays | 123 |
| Operational Cost | ₹763K |

**Major Observations:**
- Packing was the largest contributor to delays.
- 15–21 October had a high concentration of delays.
- Electronics and Toys & Games showed higher delay rates.
- Evening shift workload was comparatively high.
- Remote warehouse zones experienced more late orders.

## Project Files
The repository includes the synthetic dataset, Python notebook, analysis scripts, Power BI dashboard, validation materials, and documentation.

## How to Run
1. Download or clone this repository.
2. Install Python and Jupyter Notebook.
3. Run `pip install -r requirements.txt`.
4. Open `warehouse_analysis.ipynb`.
5. Run the notebook cells.
6. Open the `.pbip` file in Power BI Desktop to explore the dashboard.
